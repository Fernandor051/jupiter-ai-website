Tu asistente personal, conectado a WhatsApp.

Jupiter AI es un proyecto de asistente personal que permite conversar con inteligencia artificial y organizar tareas, citas y recordatorios desde WhatsApp.

Qué hace Jupiter AI

Puede responder consultas, guardar información que el usuario solicite recordar, organizar tareas y citas y gestionar recordatorios. Cada usuario se identifica de forma independiente para mantener separada su información.

Uso responsable

Jupiter AI utiliza la API oficial de WhatsApp para mensajería. No está diseñado para spam ni mensajería masiva no solicitada. Los usuarios deben iniciar o autorizar las comunicaciones correspondientes.

Soporte

Para soporte, privacidad o solicitudes relacionadas con datos, utiliza el canal de contacto oficial asociado al proyecto. Antes de publicar este sitio, sustituye este texto por un correo de soporte que controles.

Jupiter AI es un proyecto independiente y no está afiliado ni respaldado por WhatsApp, Meta u OpenAI.
